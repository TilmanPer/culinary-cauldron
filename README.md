# Culinary Cauldron (Fabric, Minecraft 26.3)

Requires JDK 25.

    ./gradlew build        # jar in build/libs/
    ./gradlew runClient    # test in-game

Gameplay: water cauldron on a lit campfire -> right-click with 4 foods/potions (max 1 potion)
-> right-click with a Ladle -> right-click with an empty Bowl.
Ladle recipe: iron ingot + 2 sticks, see data/custom_mod/recipe/ladle.json.
